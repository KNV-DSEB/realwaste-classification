# RealWaste Classification

A 10-day Deep Learning course project for real-world waste image classification.

## Project objective
Compare three CNN strategies under one fixed data/evaluation protocol:
- Simple CNN from scratch
- Custom complex Multi-Scale CNN from scratch
- EfficientNet-B0 transfer learning/fine-tuning

The project emphasizes fair comparison, reproducibility, class-level analysis, and a report structure aligned with the lecturer requirements.

Joining now? Read [`docs/HANDOVER.md`](docs/HANDOVER.md) (current state, remaining work, how to run). The original setup is in `START_HERE.md`.

## Non-negotiables
- One fixed split for all models.
- Test set untouched until final evaluation.
- No invented metrics or results.
- Training-only augmentation.
- All experiment changes recorded.
- Code freeze by end of Day 7; result freeze by end of Day 8.
